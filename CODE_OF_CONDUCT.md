# Code of Conduct

This project adopts the **[Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct.

The full text of the covenant — including expected behavior, unacceptable behavior, enforcement responsibilities, scope, and the four-tier enforcement guidelines — lives at the link above and is considered part of this project by reference.

## Reporting

Conduct concerns can be reported to the project maintainer:

- **David Jorjani** — d.jorjani@gmail.com

All reports are reviewed and investigated promptly and fairly. The maintainer is obligated to respect the privacy and security of the reporter.
